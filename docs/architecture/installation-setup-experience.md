# 首次配置与重复安装体验

状态：开发实现和隔离回归通过，尚未打包、安装或完成实际窗口操作验收。按用户优先级插入原优化计划；本轮不继续扩展缓存和词库。

## 已实现的规则

| 用户状态 | 安装后的行为 |
| --- | --- |
| 首次配置 | 注册、启用、选择输入源后打开向导；真实输入验证后再准备可选语言包 |
| 已验证键盘、向导未完成 | 保留验证进度，继续未完成步骤；不强制启用或切换输入源 |
| 已完成向导 | 保留旧完成标记；服务正常时不再打开设置 |
| 用户关闭向导或选择稍后设置 | 保存暂缓选择；正常升级不再自动弹出向导，仍可手动继续 |
| 无法读取配置状态 | 不猜测为首次安装、不强制切换；打开设置供检查 |
| 注册或翻译服务失败 | 打开设置检查，但不清空已有配置；已完成用户进入设置主页而非重走向导 |

升级预安装阶段仍退出经过验证的旧运行进程，但不再主动禁用输入源。后安装阶段对已配置用户只更新注册，不强制启用或选择，避免覆盖用户的输入源选择和禁用意图。系统实际是否在进程退出、注册期间维持当前选择，仍须真机升级验收，不能由命令夹具推断。

没有桌面登录用户时不声称会在登录后自动弹出向导；安装日志提示登录后从键盘设置启用，再从输入法菜单打开设置。

## 设置状态

- 沿用 `onboarding.completed.keyboard-and-translation`，不因升级清零。旧完成记录可以作为历史键盘配置依据。
- 新增键盘验证进度、暂缓整个设置、暂缓翻译准备三项用户选择。历史记录不是当前 controller 验收证据；输入源实际不可用时不能借历史记录完成向导。
- 完成键盘验证后切换到其他输入源、准备语言包或重开设置，不要求重复原先的验证。若输入源已经不可用，返回键盘步骤。
- 首次说明全拼/小鹤切换位置、每页五项、Tab 提交独立译文；方案实际切换仍通过输入法菜单，不由设置助手覆盖用户 Rime 配置。
- 语言包可稍后准备；静态热词和普通中文输入不应被下载步骤阻塞。
- 每次打开/激活设置只查询语言包状态，不自动下载已有或缺失的包。初始未知状态显示检查中，不误报缺包。
- 探测代次避免晚到的旧状态覆盖刚完成的语言包准备。准备取消后恢复按钮；准备返回后的状态轮询有界，不无限卡在等待中。
- 只有用户主动点击重新运行向导，才清除历史键盘验证进度；不删除语言包、词库、用户词频或个人配置。

## 实现入口

- `RoTypeSettings.swift`：进度持久化、完成条件与系统能力探测。
- `TranslationSetupView.swift` / `SettingsComponents.swift`：向导、状态说明、窗口关闭后的暂缓选择。
- 设置助手 `--setup-state`：只读查询，返回 new / resume / complete / deferred；不创建窗口或激活现有进程。
- `Installer/scripts/configure-user.sh`：按用户状态执行安装收尾，由 postinstall 调用。
