# 候选翻译区与语音输入改造进度（历史）

> 本文保留早期实施记录；当前行为以 [整体优化计划](optimization-plan.md) 和 [候选翻译协议](candidate-translation-contract.md) 为准。旧响应文件/F18/编号翻译链路已清退，不再维护第二套翻译实现。

> 0.2.31 决策更新：用户取消语音功能，相关源码、设置、依赖和打包流程已移除；下文语音路线与 Tab 切换焦点方案仅为历史记录，不再执行。当前交互为每页最多 5 项、译文不显示语言/范围标签、Tab 直接提交。范围仍保留在内部提交校验与辅助功能说明中。升级只删除合法签名的旧语音 App，保留模型和历史数据。

## 已确认的交互

- 翻译跟随当前高亮候选，所有分页一致。
- 翻译区独立于 Rime 候选编号；Tab 在两区之间切换，空格/回车或点击译文提交。
- 等待期间不能提交旧结果；当前分段与整句的提交范围必须区分。
- 语音统一快捷键设置、录音状态提示，后续实现实时草稿及识别修订。

## 当前实现（开发中，未发布）

- `RoTypeCandidateTranslationSession` 管理选择快照、请求代号、过期响应、内部焦点和可提交结果。
- Lua `rotype_candidate_session` 在主输入线程导出当前选中候选，提交前再次比对原文、输入、范围、索引。
- 全 composition 翻译直接提交；分段翻译通过新的 SimpleCandidate 和 Rime 的确认操作保留后续 composition，不改写原词典候选。
- Controller 的新展示路径不再写响应文件或用 F18 重算候选；旧 Lua 路径暂保留兼容与已有回归。
- `RoTypeTranslationPanel` 为非激活窗口，固定跟随候选窗；单行 34 pt，长译文 54 pt；鼠标提交、Tab 焦点及空格/回车已接入。
- 工厂主题改为横排、弱化编号、蓝色圆角选中块，提供明亮和深色配色。未改用户已安装配置。分页仍支持键盘与滚轮，隐藏上游占据左侧额外空间的分页箭头。
- 主语音设置页已接 `/api/settings` 的快捷键/按住或切换模式，复用现有鉴权与配置；请求版本避免旧轮询覆盖刚保存的选择。
- 现有语音 HUD 改为中文并移至屏幕底部，明确区分录音与停录后的识别。

## 已执行验证

- 会话测试：切换候选、丢弃旧结果、等待时禁提交、Tab 不触发反向翻译、会话取消。
- 真实 Rime 测试：高亮变化、第二页快照、第二页译文提交；若为部分候选，确认译文进入 composition 且后续输入保留。
- 完整 `scripts/test.sh`、Squirrel Release 构建、语音原生代码语法检查。
- `--preview-candidates <squirrel.yaml> [--dark]` 使用实际候选窗和翻译区代码渲染，12 秒后退出；不注册 IMK、不读取或部署用户 Rime 数据、不抢键盘焦点。

## 未完成，不能视为验收通过

1. 固定翻译区真实 IMK 跨应用的 Tab/点击/分页/部分提交验收。渲染预览与底层 Rime 测试不能代替这一项。
2. 快捷键页面端到端保存、监听生效、权限与冲突提示验收。
3. 语音取消、真实音量反馈、目标输入框变化保护的统一会话生命周期。
4. 实时 ASR 草稿、最终识别修订、安全上屏。已发现安装的 `mlx_qwen3_asr 0.3.5` 有 experimental streaming 实现，但尚未接入麦克风链路或做实时性能验证。
5. 新版本打包、公证、安装与升级回归。

不以后台翻译成功、静态代码检查或设计预览代替完整输入行为验收；不把实验性 streaming 直接标为产品实时能力。
