# 候选翻译协议 v2

## 语义

当前高亮候选（整句情况下包含已确认前缀）是翻译原文。输入码只用于识别输入会话与校验范围，不参与猜测翻译内容。输入法和服务共同编译 `Sources/RoTypeCore/DynamicTranslationProtocol.swift`，避免两份规则漂移。

这是中英产品策略，不是通用语言识别：

- 包含 Han 字符的候选按中→英处理，包括中英混合文本和扩展区汉字。
- 不含其他文字脚本的 Latin 文本按英→中处理，允许重音字符、组合音标与弯引号。
- 纯标点、没有支持文字的输入不生成 v2 请求。Latin 脚本不等于英语识别准确；不会宣称可以自动识别法语等所有语言。

## 请求与回复

新增 XPC selector：`translateCandidate(sessionID:generation:request:withReply:)`。

外层保留 UUID sessionID 与正整数 generation。`request` 是只包含字符串的六字段字典：

| 字段 | 约束 |
| --- | --- |
| version | 必须为 `2` |
| rawInput | 完整 Rime 输入码，非空，最多 4096 UTF-8 字节 |
| sourceText | 当前待翻译候选原文，非空，最多 4096 UTF-8 字节 |
| identity | `起点:终点:绝对选中索引`，最多 128 字节；非负且起点小于终点，终点不能越过输入码字节范围 |
| scope | `whole` 或 `segment` |
| direction | `zh-en` 或 `en-zh`，必须符合当前候选的中英策略 |

未知版本返回错误 6；字段缺失、多余、范围错误、方向冲突返回错误 1。设置角色调用新接口仍返回错误 5，且在读取请求内容之前拒绝。非法请求不能消费 generation 或取消当前合法请求。

服务校验通过后直接使用请求中的方向与原文。回复仍携带 generation、direction、sourceText、translatedText。客户端校验代次、原文、方向，再由候选 session 与最新 Rime 快照决定是否仍可提交；不匹配的响应不得上屏。

Lua 的 F19/F20 快照与提交协议保持不变。Swift 将 `raw/source/identity/scope` 转成强类型请求；方向规则不复制进 Lua。分段翻译不再把 source 塞入 rawInput 来规避旧启发式。

## 升级兼容

- v1 的 selector、参数和回复布局不变；新服务继续接收旧客户端请求。
- v1 使用同一候选文字策略推导方向，仍不依据拼音猜测原文。
- 新客户端只发送 v2。遇到尚未更换的旧服务，不自动降级为启发式请求；XPC 失败/超时进入不可提交状态，允许用户显式重试。不能从所有连接错误中准确推断“旧版本”，只有明确错误 6 才显示协议不兼容。
- v1 至少保留一个明确支持的升级周期；删除前需完成旧客户端兼容验收，不因为当前源码只有 v2 调用就立即删掉。
- 已验证当前服务同时支持 v1/v2 selector 与角色限制；真实旧二进制与新客户端的混合升级仍纳入最终安装验收，不能用同版本夹具替代。

## 恢复与错误码

共享 `CandidateTranslationFailure` 通过 NSError 的稳定 domain/code 传递。错误 4（取消）、5（权限）、6（协议）、10（缺语言包）、11（系统版本）、14（语言不支持）、15（非法响应）不立即重试；12（服务不可用）与 13（超时）在没有静态词条兜底时允许用户点击或 Tab 显式重试。

重试创建新 generation，清空旧结果；重绘、长按 Tab 和重复点击不会在加载中再发请求。用户重试成功后仍需新的提交操作。只有 SDK 的 internalError 允许一次 250ms 退避后的自动重试；取消、缺语言包和未知错误不走自动重试。

## 静态兜底

同一个强类型候选请求提供小型人工校准词表：10 组中英词条及显式历史英文别名。中文要求原文完整匹配；英文允许大小写差异及列出的别名。不根据拼音匹配，不拆词拼接句子，不把已确认前缀丢掉。

- macOS 26 以下：输入法直接进入系统不可用处理，命中词条即可使用现有译文栏，不向服务发送动态翻译请求。
- 动态请求缺语言包、服务不可用或超时：若当前请求仍有效且有静态词条，完成为可提交结果；否则保留真实错误及既有重试策略。
- 取消、权限、协议及响应不匹配等错误不以静态结果掩盖。
- 静态结果仍绑定快照与 generation，使用同一 F20 提交路径，分段时保留后续输入。静态完成后，迟到的动态结果不得替换它。
- 低版本且无匹配时明确显示“无匹配的静态译文”，不承诺任意句子的离线翻译。

词条只由共享 Swift 合约维护；旧 Lua 编号候选路径和词表已清退，仅留不生成译文的模块名兼容入口，见 [兼容说明](legacy-translation-retirement.md)。静态匹配测试与真实 Rime 提交测试已通过；它们不等于 macOS 14/15 实机或已安装 IMK 的完整端到端验收。

## 已完成验证

- 请求/回复回归：`can / 餐`、英文补全、`café`、分解音标、`don’t`、中英混合、生僻汉字。
- 未知版本、错误方向、范围、scope、空输入、多余字段、非支持脚本的拒绝；同一代次随后合法请求仍可执行。
- 原生候选会话对原文和方向的响应校验。
- 独立签名 XPC 的 v1/v2 请求投递、未知版本拒绝、ad-hoc 客户端拒绝、设置角色越权拒绝；生产见证连接保持。
- 输入法 Release 构建、常规测试和真实 Rime 分页/分段提交测试通过。未发布新安装包，也未宣称完成跨应用 IMK 验收。
