## 自动准备

- 输入法激活时，如设置 helper 未运行，验证嵌入 helper 的团队与角色签名，再在后台启动，不激活窗口。
- helper 恢复后监听原生 TIS 选中通知；仅选中洛克、模型存在且权限满足时自动准备。不会自动下载、录音、切换系统输入源或修改系统 Fn 用途。
- `VoiceActivation` 单独保存用户意图 `voice.autoEnabled`，默认 true。旧 `voice.enabled` 同时承载运行状态和失败状态，不能代表可靠的关闭意图，因此不再作为恢复依据。
- 用户明确关闭的新开关会跨重启保留。模型切换、校验、修复、加载失败、退出不覆盖它。维护会结束当前录音；完成后按意图及当前输入源恢复。
- 权限未满足时不反复弹窗；用户可在设置主动授权，返回后重新检查。
- 麦克风仍只在明确按住 Fn 后打开；安全输入、原生一次性提交票据、目标验证和不自动发送策略不变。
