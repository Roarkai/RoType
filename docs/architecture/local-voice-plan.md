# 洛克本地语音输入开发计划

起点：0.0.1 / build 38（`085af54`）。本次只定计划，不恢复旧语音链。

## 已定范围

- 默认 Qwen3-ASR 0.6B MLX 8bit，约 1.01 GB；可选 1.7B MLX 8bit，约 2.46 GB。文件大小不等于运行内存。
- 中文优先、完全本地；模型单独下载，不塞进基础安装包，不自动切云端。
- 首版按住 Fn 录音，松开结束并识别；Esc 取消；填入文字但不自动发送。
- 一个不抢焦点的语音条；不做默认润色、翻译、会议转写或边说边往应用反复改字。

## 开发顺序

| 阶段 | 要做的事 | 通过条件 |
| --- | --- | --- |
| 1. 同机验证 | 比较两款量化模型的中文短句、数字、人名、中英混读；测冷启动、收音启动、松开到结果、峰值内存 | 数据支持 0.6B 默认选择；不给未经验证的速度承诺 |
| 2. Fn 与权限 | 明确是否在 ABC 等其他输入源下全局生效；处理长按、误触、组合键、外接键盘、权限弹窗与冲突 | 不吞 Fn 组合键；取消和松开丢失不会导致持续录音；不擅改系统快捷键 |
| 3. 本地录音 | 麦克风选择、采样转换、语音检测、首尾缓冲、设备断连处理 | 不吞首尾字；无声不出字；非录音状态关闭麦克风 |
| 4. 识别进程 | 独立本地工作进程、模型预热、空闲释放、任务编号、取消、限时限长 | 不阻塞键盘；模型加载失败可恢复；取消后的迟到结果不能提交 |
| 5. 安全回填 | 绑定本次输入目标；有效 IMK 客户端优先，其他场景评估辅助功能/剪贴板回填 | 不写错窗口、不覆盖新剪贴板、不自动回车；密码框禁用；失败可复制结果 |
| 6. 热词与恢复 | 用户主动添加本地人名/术语，验证模型提示效果；取消清理；失败结果恢复入口 | 不监视完整输入历史；不把语音结果直接当成拼音学习；音频不默认长期保存 |
| 7. 验收发布 | 微信、浏览器、编辑器、终端；内置麦克风/AirPods；断网、连续录音、睡眠恢复、模型切换、升级 | 键盘与翻译回归通过；断网可识别；模型与用户词库保留；签名、公证后交付 |

## 必须守住

- 测试只在隔离输入框操作，每次回填重新校验目标；不再向未知前台窗口自动发键。
- 模型预热不等于常开麦；下载必须可取消、校验文件完整性，卸载模型不删个人词库。
- ASR 任务生命周期与拼音/翻译分离，不通过伪造普通按键驱动后台查询。
- 真正的实时音频流与“已有音频逐字输出”分开验证，不能混称流式。
- Typeless 的云端识别、上下文读取与润色不照搬；豆包未证实的 Fn 行为需实测。
- 免提模式、自动学习语音纠正、复杂上下文与实时字幕排在首版稳定之后。
