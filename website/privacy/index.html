隐私说明

更新于 2026 年 9 月 6 日，适用于当前提供的 Build 48。

中文输入与个人学习

中文输入由本地 Rime 引擎处理。个人词频等学习数据保存在用户目录，升级保留现有学习数据。你可以单独忘记某个候选的个人学习记录，而不是删除系统词库。

语音处理与麦克风

准备语音模型不会开启麦克风。选中洛克、主动按住 Fn 后才录音；Esc 可取消。麦克风权限归属「洛克输入法」，辅助功能权限归属「洛克输入法设置」，用于快捷键和输入目标检查，不记录完整按键历史。

音频写入本机私有临时目录，由独立的原生 Swift / MLX 进程运行 Qwen3-ASR。没有云端识别兜底，录音不会上传给识别服务。识别完成、取消或失败时会删除临时音频；异常退出后的残留不能视为持久恢复功能。

最近识别结果仅在应用内存中保留。只有用户主动点击复制才写入剪贴板。自动填入会检查应用和输入目标，不自动按回车发送；密码框与 Secure Input 不在支持范围内。

翻译与联网边界

动态中英翻译使用 Apple 设备端语言能力。Apple 可能收集不含原文和译文的 API 使用与性能元数据，具体以 Apple 系统说明为准。语言包准备、语音模型下载、访问项目网站和软件更新需要联网。

语音模型从设置中主动下载，校验文件大小和 SHA-256。模型下载服务会接收建立网络连接所需的信息，例如 IP 地址；这不同于上传录音。

这个官网

官网不设置注册、广告或第三方行为分析脚本，也不申请麦克风权限。配色跟随系统，页面不写入浏览器存储。

网站经 Cloudflare 和源站 Nginx 提供服务。基础访问日志及安全处理可能包含 IP 地址、请求时间、网址、浏览器信息和响应状态。外部 GitHub 等链接由对应服务按其隐私政策处理。我们不把「没有分析脚本」表述为「没有任何访问记录」。

反馈问题时

请先遮住截图中的私人内容，不要公开上传密码、完整私人录音、密钥或访问令牌。一般只需要系统版本、芯片、构建号、应用名称及复现步骤。前往问题反馈。
