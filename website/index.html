安装

SHA-256 校验

  1. 打开安装包

    跟随 macOS 安装器完成安装。

  2. 添加输入法

    系统设置 → 键盘 → 文本输入「编辑」→ ＋ → 简体中文 → 洛克输入法。

  3. 选中洛克

    从菜单栏切换，输入 nihao。翻译和语音在输入法设置中准备。

系统与权限

动态翻译需 macOS 26；macOS 14/15 尚未完成全面实机验收。语音需单独下载模型，并授权麦克风与辅助功能。目标变化或连接不可用时，保留文字，不强行填入。
