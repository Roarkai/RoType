版本说明

0.0.1 / Build 48，发布于 2026 年 9 月 6 日。

这是仍在持续验证的早期版本。当前提供 Apple Silicon 安装包，最低 macOS 14；动态 Apple 翻译需要 macOS 26。macOS 14/15 尚未完成全面实机验收，当前无 Intel 安装包。

这次更新

  • 普通终端文字不再被语音自动填入策略一律拦截。识别结果里的换行转为空格，不触发回车；目标变化或连接不可用时保留文字并显示原因。
  • 菜单图标使用系统字母徽标元数据，字母为 R。旧系统仍保留 PDF 回退；实际外观需要结合系统版本确认。
  • 设置中分别展示麦克风、辅助功能的实际授权状态，已授权显示绿色圆形对勾。
  • 最近结果明确区分已填入与保留备份，避免误以为仍需要复制。

已有能力

基于 Rime 的全拼与小鹤双拼、五项中文候选、独立动态译文与 Tab 提交、个人词频学习，以及 Qwen3-ASR 0.6B / 1.7B 本地语音。模型需单独下载，不包含在安装包中。

分发验证

软件包已通过 Developer ID 签名、Apple 公证和 Gatekeeper 检查。本版自动化测试通过 70 项 Swift Testing 测试，并完成独立键盘、候选、签名隔离等检查。公证不等于兼容性或真实麦克风体验已全面验收。

已知边界

  • 语音输入单次最长 60 秒，仅在选中洛克时响应 Fn；不支持免提录音。
  • 不保证每个应用都提供可用的原生输入连接。无法安全填入时，会保留文字作为备用，不强行写入未知目标。
  • 语音没有云端兜底、自动润色或失败录音的持久恢复功能。
  • 真实设备切换、短轻声、旧 macOS 与跨应用输入仍需要更多验证。欢迎附复现步骤反馈。

源码与许可

Build 48 源码归档包含本次构建所用的项目源文件、许可证、构建脚本和依赖版本记录。依赖获取与编译需要 Xcode 及联网；源码构建不包含发行者的签名私钥。自有代码为 MIT，Squirrel 前端为 GPL，其他依赖按各自许可使用。
